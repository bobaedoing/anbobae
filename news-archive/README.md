# news-archive — AI 신문 스크랩 아카이브 (1단계 MVP)

신문 기사를 스크랩하고 **본(사실) · 깨(의미) · 적(적용 아이디어)** 로 정리해 쌓아두는 개인 리서치 아카이브입니다.

## 지금 단계에서 되는 것

- 기사 직접 등록 (제목/날짜/언론사/카테고리/지역/키워드/본/깨/적)
- 등록한 기사 목록 보기
- 기사 클릭 시 상세 보기
- 제목 · 지역 · 키워드로 검색
- 카테고리(부동산/사업/경제/투자/정책/사회/기타)로 필터링
- 기사 수정 · 삭제

데이터는 서버나 데이터베이스가 아니라 **내 브라우저의 `localStorage`** 에만 저장됩니다. 즉, 지금 이 앱은 사진 분석(AI)도, Supabase 연결도, 기사 자동 연결 기능도 없는 순수 프론트엔드 데모입니다.

## 실행 방법

`news-archive/index.html` 파일을 더블클릭해서 여시면 됩니다. 별도 설치나 서버 실행이 필요 없습니다.

## 주의할 점

- `localStorage`는 **지금 사용 중인 브라우저에만** 저장됩니다. 다른 브라우저(예: 크롬 → 엣지)나 다른 컴퓨터에서 열면 데이터가 보이지 않습니다.
- 브라우저의 "방문 기록/사이트 데이터 삭제"를 하면 저장된 기사도 함께 지워질 수 있습니다.
- 여러 사람이 함께 보는 서비스가 아니라, 지금은 "나 혼자만 보는 로컬 저장소" 단계입니다. (다음 단계에서 Supabase를 연결하면 여러 기기에서 공유할 수 있습니다.)
